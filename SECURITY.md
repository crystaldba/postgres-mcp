## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
responsibly by opening a **private GitHub Security Advisory**
(Security tab → Report a vulnerability) rather than a public issue.

If private reporting is not available, please contact the maintainers
directly via [please open a GitHub issue tagging the maintainers to request private contact].

We will acknowledge your report within 7 business days and aim to provide
an initial assessment within 14 days. If the vulnerability is confirmed,
we will work with you on a coordinated disclosure timeline (typically up
to 90 days) and credit you in the fix, unless you prefer to remain
anonymous.

If the report is declined or determined not to be a valid vulnerability,
we will explain our reasoning.
